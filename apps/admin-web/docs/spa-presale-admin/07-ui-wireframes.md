# 07 · UI 线框图

> 用途：让 dev/designer agent 对每个页面的布局、字段、操作、角色显隐有统一心智图。
> 风格基线：AntD 5 + `ThemedLayout`（左 Sider + 顶 Header）+ Vercel 主题（6px 方角、字重 ≤600、纯色、金额/hash 用 Geist Mono）。**线框只表达布局与信息层级，不表达像素**。
> 字段以 [`03-pages.md`](./03-pages.md) §0 的**源码确认 DTO**为准（如轮次无 `name`/`targetRaiseUsd`，进度用 `soldOdd/supplyOdd`；webhook 前端打码）。

## 图例

```
[按钮]   普通按钮      [按钮]🔴 危险按钮(danger)     [按钮(灰)] 状态禁用
[标签]   AntD Tag      ▾ 下拉/选择                   ★ 仅 super_admin 可见
▓▓░░     进度条        ↗ 新标签打开(BSCscan)         ⚑ manual_override 标记
●        实时轮询开    ⓘ 提示                        — 空值
```

## 1. 全局布局壳（ThemedLayout）

所有登录后页面共用。左 Sider 菜单**按角色过滤**（accessControlProvider），顶 Header 右侧身份区。

菜单是**两级结构**：一级 = 大模块分组（可点击折叠），二级 = 功能页。未来其它大模块与「认购」并列。

```
┌────────────────────────────────────────────────────────────────────────────┐
│ OddFi Admin                                       👤 Hank · 超级管理员  ▾[退出] │ Header 64px
├───────────────┬────────────────────────────────────────────────────────────┤
│ ▼ 认购         │                                                            │ ← 一级(可折叠,默认展开)
│     总览       │                                                            │ ← 二级
│   ▌ 轮次管理   │              <页面内容 / Outlet>                            │
│     入账记录   │                                                            │
│     异常事件   │                                                            │
│     全局配置   │                                                            │
│     操作审计   │                                                            │
│               │                                                            │
│   管理员管理 ★ │             content 区 min-width 1280（固定 PC）            │ ← 平台级(顶层)
│               │                                                            │
│ ┄┄┄┄┄┄┄┄┄┄┄┄ │                                                            │
│ ▶ 结算 (未来)  │             ← 未来其它大模块：并列加一个可折叠一级分组        │
│ ▶ 风控 (未来)  │                                                            │
│  Sider 220px  │                                                            │
└───────────────┴────────────────────────────────────────────────────────────┘

折叠态：
│ ▶ 认购         │   点击「认购」收起 → 二级隐藏，再点展开
```

**菜单按角色显隐**（资源 `meta.roles`）：

| 菜单 | super_admin | operator | customer_service | finance |
|---|:--:|:--:|:--:|:--:|
| **认购**（一级分组） | ✅ | ✅ | ✅ | ❌（整组隐藏） |
| └ 总览/轮次/入账/异常/配置/审计 | ✅ | ✅ | ✅ | ❌ |
| 管理员管理 ★（平台级顶层） | ✅ | ❌ | ❌ | ❌ |

> **finance 登录后**：「认购」整组 + 管理员管理都不可见 → Sider 为空 → content 区渲染空态「本期无可用模块，请联系管理员」，不白屏。
> **未来扩展**：每个新大模块 = 一个并列的一级分组（如「结算」「风控」），各自带二级功能页与角色矩阵，互不影响「认购」。

## 6. ConfirmMutationModal — 二次确认模态（所有 mutation 复用）

```
            ┌─ 暂停轮次 · 种子轮 ────────────────────────────────┐
            │ 操作对象                                          │
            │   轮次       种子轮 (seed)                         │
            │   当前状态    进行中                               │
            │  ┌──────────────────────────────────────────┐    │
            │  │ ⚠ 暂停后用户端停止认购入口；链上到账仍发生   │    │ impact (Alert)
            │  │   （走 paused_arrival 信息流，不阻塞）。     │    │
            │  └──────────────────────────────────────────┘    │
            │  [额外字段区: migrate=目标轮▾ / resolve=处理方式▾] │ extraFields(可选)
            │                                                  │
            │  操作备注（≥10 字，会落审计）         还需 0 字     │
            │  ┌──────────────────────────────────────────┐    │
            │  │ 插入种子轮回退，临时暂停战略轮               │    │ note, rune 计数
            │  └──────────────────────────────────────────┘    │
            │  [✗ 失败时此处显示就近 Alert: 如状态机/幂等错误]    │
            │                              [取消]  [确认执行]🔴  │ 备注<10禁用确认
            └──────────────────────────────────────────────────┘
```
> 危险操作确认按钮红（danger）。提交中 loading+禁用。4xx 失败自动轮换 idempotency key，5xx/超时保持同 key。

## 13. 设计令牌速记（落地时对照 design-tokens.md）

- 主色 ink `#171717`；link/success 蓝 `#0070f3`；warning 橙 `#f5a623`；error 红 `#ee0000`。**不引第六种强调色**。
- 圆角 6px（按钮/输入），卡片 8px；**禁止 100px pill**。
- 字重 ≤600；金额/TxHash/地址用 Geist Mono；`Statistic` 已配负字距。
- 状态 Tag：进行中=success(蓝) / 未开始·已结束=default(灰) / 已暂停=warning(橙)；入账 确认=success / 待确认=processing / 异常=error。
- 危险操作（暂停/关闭/迁移/改字段）按钮 `danger`(红)。
- 列表空态用 `<Empty>`，加载用 `tableProps.loading`，不自写 Spinner。
