# 赔率 规则设计 V3

**状态：** 已本地实现并发布到 BSC Testnet，当前 `BettingPool` proxy 可用
**日期：** 2026-06-12
**基线：** 当前已实现的赔率 V2 WCL、AH 扩盘口比分结算、手动封锁、Cash Out 与串关 MVP

## 1. V3 目标

V3 在当前实现基础上扩展可开盘 line，保持现有 ABI 和结算模型：

- 已有 line 全部保留，不因为 V3 文档未列出而下线；
- 四分之一线继续按当前合约模型作为独立 market 结算，不引入 `sub_bet` 或 `parent_line`；
- WCL、信号灯、红灯容量、赔率压缩/上浮继续沿用 V2 的 `S_i/P_i/lockedOdds` 口径；
- 新增整数线 Push 和四分之一线 half win / half loss 均由 score-based settlement 统一处理。

2026-06-12 本地 Solidity 源码已按本文落地新增 line；当前 BSC Testnet 已部署地址仍以部署记录为准，新 line 需要后续升级后才可在线上开盘。

## 4. 结算语义

### 4.1 通用资金语义

- `FullWin`：整笔有效注码进入胜出部分，`claimablePayout = winStake * lockedOdds / 1e4`；
- `FullLoss`：整笔有效注码判负；
- `FullPush`：整笔有效注码退回，不进入 margin、payout tax 或瀑布；
- `HalfWin`：一半注码退款，一半注码按胜出结算；
- `HalfLoss`：一半注码退款，一半注码判负；
- 当有效注码不能被 2 整除时，余数进入退款半边。

### 4.2 AH 逐线结算

`scoreDiff = homeScore - awayScore`，下表为 `outcome=0` 主队方向结果；`outcome=1` 取相反结果，`FullPush` 仍为 `FullPush`。

| home 盘口 | `outcome=0` 结果 |
|---|---|
| `-0.25` | `scoreDiff >= 1` full win；`scoreDiff == 0` half loss；`scoreDiff <= -1` full loss |
| `-0.5` | `scoreDiff >= 1` full win；`scoreDiff <= 0` full loss |
| `-0.75` | `scoreDiff >= 2` full win；`scoreDiff == 1` half win；`scoreDiff <= 0` full loss |
| `-1` | `scoreDiff >= 2` full win；`scoreDiff == 1` full push；`scoreDiff <= 0` full loss |
| `-1.25` | `scoreDiff >= 2` full win；`scoreDiff == 1` half loss；`scoreDiff <= 0` full loss |
| `-1.5` | `scoreDiff >= 2` full win；`scoreDiff <= 1` full loss |
| `-1.75` | `scoreDiff >= 3` full win；`scoreDiff == 2` half win；`scoreDiff <= 1` full loss |
| `-2` | `scoreDiff >= 3` full win；`scoreDiff == 2` full push；`scoreDiff <= 1` full loss |
| `-3` | `scoreDiff >= 4` full win；`scoreDiff == 3` full push；`scoreDiff <= 2` full loss |
| `+0` | `scoreDiff >= 1` full win；`scoreDiff == 0` full push；`scoreDiff <= -1` full loss |
| `+0.25` | `scoreDiff >= 1` full win；`scoreDiff == 0` half win；`scoreDiff <= -1` full loss |
| `+0.5` | `scoreDiff >= 0` full win；`scoreDiff <= -1` full loss |
| `+0.75` | `scoreDiff >= 0` full win；`scoreDiff == -1` half loss；`scoreDiff <= -2` full loss |

### 4.3 OU 逐线结算

`totalGoals = homeScore + awayScore`，下表为 `outcome=0` Over 结果；`outcome=1` Under 取相反结果，`FullPush` 仍为 `FullPush`。

| 盘口 | Over 结果 |
|---|---|
| `0` | `totalGoals >= 1` full win；`totalGoals == 0` full push |
| `0.5` | `totalGoals >= 1` full win；`totalGoals == 0` full loss |
| `1` | `totalGoals >= 2` full win；`totalGoals == 1` full push；`totalGoals == 0` full loss |
| `1.5` | `totalGoals >= 2` full win；`totalGoals <= 1` full loss |
| `1.75` | `totalGoals >= 3` full win；`totalGoals == 2` half win；`totalGoals <= 1` full loss |
| `2` | `totalGoals >= 3` full win；`totalGoals == 2` full push；`totalGoals <= 1` full loss |
| `2.25` | `totalGoals >= 3` full win；`totalGoals == 2` half loss；`totalGoals <= 1` full loss |
| `2.5` | `totalGoals >= 3` full win；`totalGoals <= 2` full loss |
| `2.75` | `totalGoals >= 4` full win；`totalGoals == 3` half win；`totalGoals <= 2` full loss |
| `3` | `totalGoals >= 4` full win；`totalGoals == 3` full push；`totalGoals <= 2` full loss |
| `3.5` | `totalGoals >= 4` full win；`totalGoals <= 3` full loss |

## 5. 赔率与风控

- 每条 line 是独立 market，独立维护 `S_i/P_i`、WCL、信号灯和 quoteVersion；
- 四分之一线也是独立 market，不再要求拆到相邻子线；
- Base Odds 继续由后端按既定口径生成后写链上，合约只校验赔率下限、精度和数组长度；
- 对四分之一线，后端可用相邻整数/半球线的参考赔率作为运营校验，但这不是链上强制规则；
- 大额下注滑点仍按当前 market 的单笔请求金额判断，不拆成两笔子注单判断。

## 6. 串关

串关继续使用当前合约语义：

- Full win leg：按 `lockedOdds` 进入组合因子；
- Full push / void leg：不计入组合赔率；
- Half win leg：按 `(lockedOdds + 1.00) / 2` 进入组合因子；
- Half loss leg：按 `0.5` 进入组合因子；
- 本期不支持串关 Cash Out。
