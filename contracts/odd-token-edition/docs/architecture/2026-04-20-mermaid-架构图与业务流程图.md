## 2. 下注与结算主流程

```mermaid
sequenceDiagram
    participant U as User
    participant B as BettingPool
    participant SM as BettingSettlementModule
    participant L as LiquidityPool
    participant S as StakingPool

    U->>B: placeBet(...)
    B->>B: 风控校验 / 写注单 / 收下注税
    B-->>U: 返回 betId

    Note over B: 赛果确定后
    loop 分批处理注单
        B->>SM: settleMarketBetsByScore(marketId, homeScore, awayScore, betIds) delegatecall
        SM->>SM: 按比分推导 1X2 / AH / OU 结果
    end
    B->>SM: finalizeMarketSettlement(marketId, 0) delegatecall
    SM->>L: distributeMargin(...)
    SM->>L: distributeLoss(...)
    SM->>SM: _waterfall(L2 -> L3 -> L4)

    U->>B: claimPayout(betId)
    B->>L: requestPayoutLiquidity(...) (如需要)
    B->>S: notifyReward(...) (派奖税质押份额)
    B-->>U: ODD payout
```

## 2.1 退款 / 取消终态流程

```mermaid
sequenceDiagram
    participant Ops as Backend / Settler
    participant B as BettingPool
    participant SM as BettingSettlementModule
    participant U as User

    Ops->>B: finalizeMarketSettlement(marketId, 1/2)
    B->>SM: delegatecall
    SM->>SM: mark market Refunded / Cancelled
    Note over SM: 不遍历注单，不计算 margin，不执行瀑布
    Ops->>B: refundBets(marketId, betIds, refundAmounts)
    B->>SM: delegatecall
    SM-->>U: refund ODD per bet
```

## 3. 推荐奖励流程

```mermaid
sequenceDiagram
    participant U as User
    participant B as BettingPool
    participant R as Referrer
    participant V3 as PancakeV3 Router

    U->>B: placeBet(..., referrer)
    B->>B: referrers / referrerRewardsOdd 记账

    alt 直领 ODD
        R->>B: claimReferralRewards(oddAmount)
        B-->>R: ODD
    else 签名换 USDT
        R->>B: claimUSDTReferralRewards(..., signature, ...)
        B->>B: 验签 + deadline + nonce
        B->>V3: exactInputSingle(ODD -> USDT)
        V3-->>R: USDT
    end
```
