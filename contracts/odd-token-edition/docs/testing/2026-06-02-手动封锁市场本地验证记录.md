**状态：** 通过

## 1. 验证结论

- 未手动封锁时，market 在 `block.timestamp < matchEndTime` 前仍可下注、预览和更新赔率；
- `block.timestamp >= matchEndTime` 后下注和预览关闭，赛后结算路径保持可用；
- `OPERATOR_ROLE` 可在 `block.timestamp <= matchEndTime` 调用 `lockMarket(marketId)` 手动封锁单个 market；
- 手动封锁后 market 进入 `Locked`，`lockAt` 更新为封锁区块时间，`quoteVersion` 自增，旧 quote guard 失效；
- 手动封锁后 `previewSignal / placeBet / updateOdds` 均回滚；
- AH / OU / 1X2 比赛与 line 相关本地测试、fork 测试继续通过。
