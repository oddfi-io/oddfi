# 赔率 V2 WCL 落地测试记录

**日期：** 2026-05-28
**范围：** `BettingOddsLib`、`BettingPool`、`BettingSettlementModule` 的 V2 S/P 风控改造

## 测试结论

已通过本地非 fork、BSC Mainnet fork 与 BSC Testnet 原址升级后验证：

- `payoutByOutcome/P_i` 按逐笔 `lockedOdds` 累加；
- Base Odds 更新不回算历史 `P_i`；
- 红灯容量按 V2 `O_new=max(BaseOdds×0.88,1.01)` 反解；
- 信号灯阈值按 V2 左开右闭；
- AH full push 释放退款注单 S/P，整盘 full push 时 market S/P 自然归零；
- AH half loss/half win 只释放退款部分 S/P；
- AH 10 条盘口线保持可开盘、可结算。
- BSC Testnet 现有 proxy 已原址升级到赔率 V2 implementation 与新的 `BettingSettlementModule`。
