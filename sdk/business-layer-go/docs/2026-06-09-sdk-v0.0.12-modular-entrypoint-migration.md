## 〇、上游这次改了什么（概要）

2026-06-08 上游把 `BettingPool` 重构为**模块化入口壳**：proxy 保留全部公共 ABI、权限、暂停、重入保护、storage 与模块路由，
重逻辑下沉到 5 个 `delegatecall`/`staticcall` 模块（Bet / Market / Referral / Settlement / Parlay）。
**proxy 地址不变**，但顺带新增了 4 个面向用户/前端的公共查询接口、3 个模块治理 setter、3 个模块地址 getter，
并对串关估值接口做了**破坏性签名变更**。

> 模块化是合约内部架构变化，对业务层基本透明（仍只对接 `BettingPool` proxy）。
> 本次业务层改动只围绕「新增的对外接口」和「破坏性签名变更」。

## 一、合约新增/变更的外部方法 → 本项目对应的库（Go 包）

业务层按角色分包：`admin`（管理员/SETTLER 角色，直签）、`relay`（用户态、sponsored/meta-tx）、`read`（只读视图）。

| 库 | Go 方法 | 状态 |
|---|---|---|
| **read**（只读） | `GetClaimStatus`、`EstimateBetValue`、`GetParlayClaimStatus`、`GetMatchMarketIds` | ✅ 新增 |
| **read**（只读） | `EstimateParlayValue` | ⚠️ 破坏性签名变更（见 §三） |
| **read**（只读） | `BetModule`、`MarketModule`、`ReferralModule` | ✅ 新增（运维/健康检查） |
| **admin**（直签） | `SetBetModule`(+WithReceipt)、`SetMarketModule`(+WithReceipt)、`SetReferralModule`(+WithReceipt) | ✅ 新增 |
| **relay** | —（本次无新增用户写接口） | — |

原始映射（合约外部方法 → SDK 方法 → 角色 → 包）：

### BettingPool — 新增公共查询接口（staticcall 转发到模块）

| 合约外部方法 | SDK 方法 | 角色 | 本项目包.方法 |
|---|---|---|---|
| `getClaimStatus(user, betId) → (won, reward)` | `BettingPool().GetClaimStatus` | view（任意调用方） | `read.GetClaimStatus` |
| `estimateBetValue(user, betId) → (estimatedValue, floatingPnL)` | `BettingPool().EstimateBetValue` | view | `read.EstimateBetValue` |
| `getParlayClaimStatus(user, parlayId) → (won, reward)` | `BettingPool().GetParlayClaimStatus` | view | `read.GetParlayClaimStatus` |
| `estimateParlayValue(user, parlayId) → ParlayEstimatedValue` | `BettingPool().EstimateParlayValue` | view | `read.EstimateParlayValue`（⚠️ 见 §三） |
| `getMatchMarketIds(matchId) → bytes32[]` | `BettingPool().GetMatchMarketIds` | view | `read.GetMatchMarketIds` |
| `betModule() / marketModule() / referralModule()` | 同名 SDK getter | view | `read.BetModule / MarketModule / ReferralModule` |

### BettingPool — 新增模块治理 setter（DEFAULT_ADMIN_ROLE）

| 合约外部方法 | SDK 方法 | 角色 | 本项目包.方法 |
|---|---|---|---|
| `setBetModule(addr)` | `SetBetModule` / `...Calldata` | ADMIN | `admin.SetBetModule` |
| `setMarketModule(addr)` | `SetMarketModule` / `...Calldata` | ADMIN | `admin.SetMarketModule` |
| `setReferralModule(addr)` | `SetReferralModule` / `...Calldata` | ADMIN | `admin.SetReferralModule` |

> 已有的 `admin.SetParlayModule`（v0.0.11）保持不变；本次把缺失的另外三个模块 setter 补齐，四个模块全覆盖。

### LiquidityPool — 新增方法**故意不接入**

SDK v0.0.12 还暴露了 `OpenMatchPool / CloseMatchPoolDeposit / DistributeLoss / DistributeMargin / RequestPayoutLiquidity`
（+`...Calldata`）。经核对合约源码，这 5 个方法在 `LiquidityPool.sol` 均为 **`onlyBettingPool`**——
只能由 `BettingPool` 合约内部调用，任何运营 EOA 直接调用都会 revert。

→ **结论：业务层不暴露**。SDK 作为薄绑定层会生成所有方法，但本层按「外部可调用性」过滤，不纳入 `admin`。

## 三、⚠️ 破坏性变更：`read.EstimateParlayValue`

签名变化：

```go
// before (v0.0.11) — 走 BettingParlayLens，无 user
func (c *Client) EstimateParlayValue(ctx, parlayID coretypes.ParlayID) (ParlayEstimate, error)

// after (v0.0.12) — 走 BettingPool proxy wrapper，新增 user
func (c *Client) EstimateParlayValue(ctx, user common.Address, parlayID coretypes.ParlayID) (ParlayEstimate, error)
```

两点行为变化，调用方必须知悉：

1. **新增 `user` 入参**，且查询是 user-scoped：只有 owner 本人名下、且仍处于 `Pending` 的串关才返回值；
   owner 不匹配或不存在返回**全 0 默认值**；非 `Pending` 状态（已结算/可退/已退）会 **revert**。
2. **`ParlayEstimate` 增加 `FloatingPnL`**（`int256` → `decimal.Decimal`，过程浮动盈亏 = 估值 − 本金，可为负，仅展示用）。
   单注侧的 `BetEstimate` 同样带 `FloatingPnL`。

> 旧代码若在「结算后」调用 `EstimateParlayValue` 展示最终值，需迁移：结算后该接口已 revert，
> 应改用 `GetParlayClaimStatus`（赛后是否赢 + 净可领额）。e2e 测试已按此调整。

`PreviewParlay` 不受影响（仍走 `BettingParlayLens`，签名不变）。

## 四、新增对外接口速查（read）

| 方法 | 入参 | 返回 | 语义 |
|---|---|---|---|
| `GetClaimStatus(ctx, user, betID)` | 用户地址、单注 ID | `ClaimStatus{Won, Reward}` | 单注赛后是否赢 + 净可领（ODD wei，已扣派奖税）；未到 matchEnd 时 revert；未知/不匹配返回 (false,0) |
| `EstimateBetValue(ctx, user, betID)` | 用户地址、单注 ID | `BetEstimate{EstimatedValue, FloatingPnL}` | Pending 单注过程估值 + 浮动盈亏（仅展示，不可领/不可提/非 Cash Out 报价） |
| `GetParlayClaimStatus(ctx, user, parlayID)` | 用户地址、串关 ID | `ClaimStatus{Won, Reward}` | 串关赛后状态；`Refundable` 时 `Won=false` 而 `Reward` 为可退本金 |
| `EstimateParlayValue(ctx, user, parlayID)` | 用户地址、串关 ID | `ParlayEstimate{…, FloatingPnL}` | 仅 Pending 串关；非 Pending revert（见 §三） |
| `GetMatchMarketIds(ctx, matchID)` | 比赛 ID | `[]coretypes.MarketID` | 某场比赛下所有 marketId |
| `BetModule / MarketModule / ReferralModule(ctx)` | — | `common.Address` | 当前模块 implementation 地址（运维/升级核对） |

`ClaimStatus.Reward` / `BetEstimate.*` / `ParlayEstimate.*` 金额均为 `decimal.Decimal`（ODD wei，未缩放），
odds 类字段（`LockedComboOdds`）已 `/1e4`，与项目既有约定一致。
