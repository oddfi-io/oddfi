## 一、合约新增的外部方法 → 本项目对应的库（Go 包）

业务层按角色分包：`admin`（管理员/SETTLER 角色）、`relay`（用户态发起、sponsored/meta-tx）、`read`（只读视图）。
下表为合约新增外部方法、SDK v0.0.11 暴露的方法，以及本项目落地的包与 Go 方法。

> ✅ 已实现（2026-06-07）：`relay/parlay.go`、`admin/parlay.go`、`read/parlay.go`，
> 共享类型 `coretypes.ParlayID` / `coretypes.ParlayLegInput`，并在 `clients.go` 接通
> `BettingParlayLens` 地址。`admin`/`relay` 每个写方法都有 A 形态（返回 tx）与 `WithReceipt` 形态（等回执）。

| 库 | Go 方法（A / B 形态） |
|---|---|
| **relay**（Magic 代付） | `PlaceParlay` / `PlaceParlayWithReceipt`，`ClaimParlayPayout` / `ClaimParlayPayoutWithReceipt` |
| **admin**（直签） | `SettleParlay`(+WithReceipt)、`ReleasePayoutReserve`(+WithReceipt)、`SetParlayModule`(+WithReceipt) |
| **read**（只读） | `GetParlay`、`GetParlayLeg`、`OpenParlayMaxPayout`、`MarketFinalResult`、`PreviewParlay`、`EstimateParlayValue` |

原始映射（合约外部方法 → 角色 → 包）：

### BettingPool（核心，含 delegatecall 到 ParlayModule）

| 合约外部方法 | SDK 方法 | 角色 | 本项目目标包 |
|---|---|---|---|
| `placeParlay(legs, stake, minComboOdds, deadline, referrer)` | `PlaceParlay` / `PlaceParlayCalldata` | 用户 | **relay**（对标 `PlaceBet`） |
| `claimParlayPayout(parlayId)` | `ClaimParlayPayout` / `...Calldata` | 用户 | **relay**（对标 `CashOut`/claim） |
| `settleParlay(parlayId)` | `SettleParlay` / `...Calldata` | SETTLER | **admin**（对标 `SettleMarketBetsByScore`） |
| `releasePayoutReserve(riskId)` | `ReleasePayoutReserve` / `...Calldata` | SETTLER | **admin** |
| `setParlayModule(addr)` | `SetParlayModule` / `...Calldata` | ADMIN | **admin** |
| `initializeV3()` | （reinitializer，部署脚本侧） | ADMIN | 部署/迁移脚本 |
| `parlays / parlayLegs / getParlay / getParlayLeg` | `GetParlay`, `GetParlayLeg` | view | **read** |
| `openParlayMaxPayout()` | `OpenParlayMaxPayout` | view | **read** |
| `marketFinalResults(marketId)` | `MarketFinalResult` | view | **read** |
| `parlayModule()` / `nextParlayNonce()` | `ParlayModule`, `NextParlayNonce` | view | **read** |

### BettingParlayLens（新增只读合约，下注前预览/估值）

| 合约外部方法 | SDK 方法 | 本项目目标包 |
|---|---|---|
| `previewParlay(pool, legs, stake, user)` | `Client.BettingParlayLens().PreviewParlay` | **read**（新增 lens 封装） |
| `estimateParlayValue(pool, parlayId)` | `Client.BettingParlayLens().EstimateParlayValue` | **read** |

### LiquidityPool（储备金释放 / 全局可请求流动性）

> 资金分配方法（`distributeGlobalLoss/Margin`、`releasePayoutReserve`）合约侧为 `onlyBettingPool`，
> 由合约内部触发，业务层一般**不直接调用**；SDK 仍生成了绑定，按需用于运维/对账。

| 合约外部方法 | SDK 方法 | 本项目目标包 |
|---|---|---|
| `getGlobalRequestableLiquidity()` | `GlobalRequestableLiquidity` / `GetRequestableLiquidity` | **read** |
| `initializeGlobalRequestableLiquidity(value)` | `InitializeGlobalRequestableLiquidity` | **admin**（运维） |
| `distributeGlobalLoss / distributeGlobalMargin / releasePayoutReserve` | 同名 SDK 方法 | （内部调用，运维/对账用） |

### 治理/配置（SDK v0.0.11 一并补齐的 BettingPool 方法）
`SetTaxConfig`、`SetRiskConfig`、`SetMarginSplit`、`SetPlatformTreasury`、`SetReferral*`、`Pause`/`Unpause`、`SetBettingDependencies` 等 → **admin**（治理子集，按需暴露）。

## 二、待在本项目复原实现的测试（来自 oddfi-ODD）

合约仓新增 3 个测试文件，业务层需在对应包补等价的 e2e/单测（参考既有 `*_e2e_test.go` 模式）。

### `test/ParlayModule.t.sol` — 串关核心功能
- `testParlayFullWinClaimAndEstimatedValue` — 2 腿全中：下注(Pending,maxPayout=stake×组合赔率) → 敲定赛果 → `settleParlay`(WonUnclaimed) → lens 估值=最终值 → `claimParlayPayout` 扣 payout tax 到账。
- `testRawPayoutAboveCapStillPlacesWithCappedMaxPayout` — 6 腿超额：`previewParlay` 返回 `cappedByPayout=true`，`maxPayout` 封顶（30000）；下注后 maxPayout 取封顶值。
- `testSameMatchParlayReverts` — 同一 `matchId` 两条腿 → revert（禁止同场关联）。

### `test/FundsFlowMatrix.t.sol` — 资金流矩阵（普通 + 串关对照）
- `testOrdinaryWinClaimFundsFlowUsesMatchAndGlobalLp` — 普通注中奖：动用 match 池 + 全局 LP。
- `testOrdinaryRefundFundsFlowRollsBackRisk` — 普通注退款：风险敞口回滚。
- `testOrdinaryCashOutFundsFlowRetainedAndProfit` — 普通注 cashout：留存与利润核算。
- `testParlayWinClaimFundsFlowUsesGlobalLpOnly` — 串关中奖：**只动全局 LP**，不碰单注 match 池。
- `testManualReleaseUnclaimedParlayReserveUnlocksGlobalLp` — 未领取串关储备可由 `releasePayoutReserve` 手动释放回全局 LP。
- `testParlayRefundableFundsFlowDoesNotPullLpOrPayoutTax` — 串关可退款路径：不拉 LP、不收 payout tax。
- `testParlayPartialRefundBooksMarginOnlyAndHasNoCashOutPath` — 串关部分退款：仅记 margin，无 cashout 路径。

### `test/EndToEndFundsChain.t.sol` — 端到端资金链路
- `testFullFundsChainStakingLiquiditySingleAndParlay` — 质押 + 流动性 + 单注 + 串关全链路资金守恒。
