# Chat Agent 本地测试报告

**日期：** 2026-05-23  
**范围：** 单 Agent Chat SSE、Memory 编排、Brave Search MCP web_search tool、配置 schema、HTTP 测试页面。

## 1. 测试对象

- `ChatAgentService`：
  - `system -> runtime_context -> registered_tools -> retrieved_memories -> untrusted_input` prompt 顺序。
  - Memory.search 失败降级为空上下文。
  - SSE 事件顺序：`meta -> token -> done`。
  - Memory.search 完成后、LLM stream 打开前异步调用 Memory.write。
  - 请求 Chat LLM 时带 `<registered_tools>` prompt 和 OpenAI-compatible `tools` 字段。
  - LLM streaming content delta 会立即输出给用户。
  - LLM 返回 streamed `web_search` tool call 后，服务拼接 tool call、执行工具、回填 tool result，再继续下一轮 SSE stream。
  - `<think>...</think>` reasoning 片段不再过滤，按模型输出原样展示。
- `BraveSearchMcpTool`：
  - 生成 `web_search` function tool definition。
  - 调用 Brave MCP `brave_web_search`。
  - 只保留 title、url、content 字段。
- HTTP：
  - `GET /chat-test` 读取并返回 `test/chat-agent/chat-test.html` 本地测试页面。
  - 页面内置四个手工验收场景：
    - 输入 `我喜欢C罗`，预期 SSE 输出 LLM 信息并后台写入 Memory。
    - 输入 `我最喜欢的足球运动员是谁`，预期输出 C 罗相关。
    - 输入 `1+2`，预期输出被阻拦信息。
    - 输入 `今天的篮球比赛有哪些？`，预期触发 `web_search` 并返回搜索结果，不应输出搜索失败。
  - `POST /api/chat` 要求 `x-user-id`。
  - `POST /api/chat` 返回 `text/event-stream`。
- 配置：
  - `config/odd-agent.example.yaml` 能通过 schema。
  - `chatllm` 和 `memory.llm` / `memory.embedding-llm` / `memory.embedding-db` 能解析。
  - `tools.max_tool_calls` 和 `tools.brave-search` 能解析。
