## 流动池页面新增精选赛事数据下发
要求：
- 前端展示：
  - 比赛国家icon
  - 国家（队伍）名称
  - 比赛开始时间 ，根据浏览器时间，并显示时区

## 接口初步定义
需要在 handler/BuildMarket地方加两个接口

- 一个赛事数据详情接口，只筛选未开赛的数据下发：可以命名参考 /liquidity/details/market_all
  - 支持多语言 locale,默认 zh

- 一个按队伍名字模糊搜索的接口 ：可以命名参考  /liquidity/details/market_search?name 
  - 支持多语言 locale,默认 zh

- 2 个接口都需要支持分页
  
- 排序：默认按照比赛的累计下注量，统计用户在该比赛的累计下注量，如果下注量相同的按开赛时间，最近的排在前面

- “未开赛”的状态定义：用 state_id IN (1, 13) AND starting_at_timestamp > now。
- 排序范围逻辑修正，默认按照比赛的累计下注量，统计用户在该比赛的累计下注量，如果下注量相同的按开赛时间，最近的排在前面
- market_search?name 只返回未开赛
- 搜索只要匹配对应当前语言队名

## 注意这里的排序逻辑是根据比赛的累计下注量的来的
目前下注统计没有做，这个逻辑应该在 web-api 服务的下注的函数里统计每个赛事 fixture_id 和对应的下注次数的累计，可以初步存在 Redis 缓存中，设置不过期，需要参考本仓库上一级目录的 web-api仓库里的 ARCHITECTURE.md文档在动手联合修改两个仓库的代码
- web-api 服务的下注的函数：本次只考虑  /account/bet_place 函数
