# 需求背景与目标

## 1.1 背景

首页缺少高密度运营位。世界杯 / 欧洲杯 / 世预赛等顶级赛事期间，**夺冠盘**、**球星 prop**、**赛事大奖（金球 / 金靴 / 金手套）** 是流量与下注转化最高的玩法，但当前 Market 按联赛分类陈列，这些热点被埋在深层；运营无法在首屏快速突出某个玩法或某场关键对阵。

- 首页新增 5 种 banner 下注玩法，具体逻辑如下

## 1.2 目标

| 目标                                                         | 衡量指标                                       |
| ------------------------------------------------------------ | ---------------------------------------------- |
| 首页提供 5 个固定槽位的榜单 Banner，覆盖 Outright 与 Player Prop 两大核心玩法 | 5 个模板（`B1~B5`）100% 后端可配               |
| 视觉模板固定、内容动态：运营改文案 / 赔率 / 选项不依赖前端发版 | 改配置 → 用户可见 ≤ 5 分钟（含 CDN TTL ≤ 30s） |
| 卡片直达对应 `market_id` / `selection_id`，缩短"看到 → 投注"路径 | 卡片曝光 → 点击 → 投注三段转化纳入运营周报     |
