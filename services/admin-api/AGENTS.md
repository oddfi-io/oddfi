# 项目专属 Codex / Claude Code 编码规范

## 启动要求

- 每次对话开始处理本项目代码前，必须先读取并遵守本文件 + `CLAUDE.md`
- 如果用户在对话中补充了更严格的规则，以用户最新要求为准

## 中文注释要求

每次新增或修改代码时，必须为新增或修改的关键逻辑补充清晰的中文注释。

注释重点包括：

1. 复杂业务逻辑
2. 状态机逻辑
3. 并发控制逻辑
4. 错误处理逻辑
5. 边界条件
6. 金融、交易、链上、价格、风控相关逻辑
7. 不直观的算法或数据结构

要求：

- 注释使用中文
- 注释解释"为什么这么做"，不要只复述代码做什么
- 简单自解释代码不需要强行加废话注释
- 修改已有函数时，如果行为发生变化，需要同步更新函数注释或附近说明

## 回写项目根目录的 ARCHITECTURE.md 文件

每次代码有更新之后，需要回写项目根目录的 `ARCHITECTURE.md` 文件，确保文件内容与项目架构一致。
