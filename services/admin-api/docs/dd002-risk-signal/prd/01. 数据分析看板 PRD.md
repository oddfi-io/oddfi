## 全局框架

### 顶栏（Top Bar）

对应 TSX 组件：`TopBar`。

| 字段 | 字段定义 | 展示方式 | 规则 |
|---|---|---|---|
| 品牌标识 | Platform Analytics / 数据分析看板 | 左侧 Logo + 双行文字 | 固定展示 |
| 实时数据指示 | 系统数据实时同步状态 | 脉冲圆点 + "实时数据" | 固定展示 |
| 时钟 | 当前时间 | `YYYY-MM-DD HH:mm:ss` 格式，每秒更新 | JS `tick()` 驱动 |
| 通知铃铛 | 审批中心入口 | 铃铛图标 + 红点 badge | 点击打开审批中心（两 Tab：赛事审批 / Claim 审批；默认赛事审批） |
| 用户身份 | 当前登录用户信息 | session-chip | 来自 Lark SSO 登录态 |

### 全局展示规则

| 维度 | 规则 |
|---|---|
| 金额单位 | 默认 `USD`，使用 `$` 前缀。支持精确值 `$31,820` 和缩写值 `$48.3M`、`$312K` |
| 百分比 | 统一展示为 `%` |
| 时间 | 统一展示为 `YYYY-MM-DD HH:mm:ss` 或 `YYYY-MM-DD HH:mm` |
| 主指标 | 大号数字展示 |
| 辅助指标 | 小卡片或副文案展示 |
| 响应式断点 | `900px`（导航/网格切换）、`700px`（漏斗/行布局切换）、`600px`（紧凑模式） |

## 11. 登录流程

共 5 个流程页，顺序执行。

| 步骤 | 页面 | 展示内容 | 交互规则 |
|---|---|---|---|
| 1. 登录页 | `loginScreen` | "企业管理后台" + "使用 Lark SSO 登录" 按钮 | 点击按钮弹出 SSO 域名选择 |
| 2. SSO 域名选择 | `ssoDialogBox` | 企业域名输入框 + 后缀下拉（`.larksuite.com` / `.feishu.cn` / `.larkoffice.com`） | 输入域名后"下一步"可用 |
| 3. 跳转中 | `redirectingScreen` | "正在跳转到 Lark" + 进度条自动填充 | 自动过渡 |
| 4. 验证中 | `verifyingScreen` | "验证中，请稍候" + 进度条 + 三步验证提示（OAuth 授权码 → 访问令牌 → 安全会话） | 自动推进 |
| 5. 错误页 | `errorScreen` | "授权失败" + 错误代码 `AUTH_FAILED_001` + 重新登录按钮 | 点击"重新登录"返回步骤 1 |

登录成功后进入首页（p5），写入操作日志 `lark.sso.login`。

## 13. 异常场景

| 情况 | 信号 | 触发策略 |
|---|:---:|---|
| Claim 金额为空 | 🟡 | 表格显示 `—` |
| 赛事审批队列为空 | 🟡 | 面板显示"当前没有红灯赛事待审批" |
| 图表数据为空 | 🟡 | 保留容器，不报错 |
| 指标值无法计算（分母为 0） | 🟡 | 展示 `—`，不阻塞页面渲染 |
| AI 结论生成失败 | 🟡 | 展示"数据不足，无法生成结论" |
| 红灯赛事审批后状态变更 | 🟢 | 首页高风险事件数、审批 badge、赛事列表必须同步更新 |
| 无权限访问页面 | 🔴 | 拦截访问，写入操作日志 `access.denied` |
| 登录授权失败 | 🔴 | 展示错误页，错误代码 + 重试按钮 |
| 所有风险指标不达标 | 🔴 | 平台诊断模块顶部横幅提示 |

## 14. 验收标准

| 验收项 | 标准 |
|---|---|
| 页面完整性 | 7 个主页面 + 4 个弹窗浮层 + 登录流程全部实现 |
| 首页字段口径 | 同一字段在所有模块中数值和解释一致 |
| 平台分析文案 | 由前端规则自动生成，不允许写死固定文案 |
| Claim 审批逻辑 | `pending > 5000U` 自动进入 `Request`，且支持审批动作 |
| 赛事审批逻辑 | 仅红灯赛事进入审批中心，审批动作后状态同步 |
| 收入结构口径 | 本周净收入、手续费收入、核心收入占比保持一致 |
| 风险灯规则 | `L` 阈值映射必须与绿黄橙红规则一致 |
| 表格展示 | 同一模块内一行一个字段，字段顺序固定 |
| 页面结构 | 严格按 HTML 页面输出，不新增页面层级 |
| 权限控制 | 用户信息（p4）和平台管理（p7）需 `view` 权限才可访问 |
| 权限联动 | `delete` 自动包含 `approve`；`approve` 自动包含 `view` |
| 审批 badge | 铃铛红点 = 赛事审批 badge + Claim 审批 badge 总数 |
| 用户分层点击 | 6 个分层卡片点击后弹出对应用户列表浮层 |
| 登录流程 | SSO 5 步流程完整，授权失败有错误页 + 重试 |
| 操作日志 | 登录、权限变化、审批动作均写入操作日志 |
| 响应式 | `<=900px` 导航水平化；`<=700px` 漏斗垂直化；`<=600px` 紧凑模式 |
