**Admin 后台看板按 6 页 + 全局组件 + 审批中心 + 分层下钻共拆解 43 个接口；除 Withdraw 审批 3 个接口直接复用 `oddfi-backend` 现有 `/admin/order/*` 标 `[已有]` 外，其余 40 个均标 `[新增]`。**

本文档严格按改后的 HTML 模块（删除买入税 / 卖出税 / LP 抽成，新增 Bet / Claim / LP 收入三类）逐模块映射前端 UI 数据点到后端字段。各接口对照代码库 `07 代码库` 的真实落地见 §11「代码现状」列（实测：✅ 已实现 9 / 🟡 部分·路径不同 4 / ❌ 未实现 30）。**真实上线的 admin 前后端 `oddfi-admin-backend`/`oddfi-admin-frontend` 已落地 Lark 登录与管理员管理（路径不同），本看板分析类接口仍未建。**

> 首页 / ① 用户信息 / ② 资产信息 / ③ 邀请返佣 / ④ 赛事纬度 / ⑤ 手续费管理 / ⑥ 平台管理 / 认证 / 审批中心 / 分层下钻

# 0. 状态标注与约定

- `[已有]`：直接复用 `oddfi-backend` 真实接口（路径与字段不动，见 `01. oddfi-backend-openapi.yaml`）
- `[新增]`：Admin 看板专用，本次需后端新设计

约定：

- Admin 看板所有新接口统一前缀 `/api/v1/admin/*`，独立于现有 `web-api`
- 金额字段统一 `string`（decimal），比例字段统一 `number`（0–1 小数），时间字段统一 ISO 8601
- 列表接口统一支持 `page` / `page_size` / `sort_by` / `sort_order`

# 概述

- **服务划分**：`admin-api`（新增）覆盖看板 40 个聚合接口；提现审批沿用 `web-api` 现有 `/admin/order/*` 3 个接口
- **复用边界**：仅 Withdraw 审批 3 接口（`pending_orders` / `approve_order` / `order_info`）`[已有]`，其余 40 接口 `[新增]`
- **手续费结构变更**：旧字段 `swap_buy_tax_*` / `swap_sell_tax_*` / `swap_dex_fee_*` / `lp_fee_*` 全部弃用，由新版 `bet_total` / `claim_total`（含 `claim_revenue` + `claim_no_referrer` 2 子项）/ `lp_revenue` 取代
- **金额 / 比例 / 时间统一**：金额 `string` decimal、比例 `0–1 number`、时间 ISO 8601；列表统一 `page` / `page_size` / `sort_by` / `sort_order`
- **认证独立**：Admin 走 Lark SSO（`/api/v1/admin/auth/sso/*` 新增），不复用 Web 端钱包登录 `/account/login_by_wallet`
- **硬结论**：**先把 `/admin/order/*` 三接口的字段对齐到看板 Withdraw 审批 Tab，再开新增 40 接口的设计排期；Bet / Claim / LP 三类收入字段是新版手续费的唯一真源，不要再回填旧 `swap_*` 字段**
